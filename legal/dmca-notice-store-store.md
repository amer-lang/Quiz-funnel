## After sending

- AWS usually acknowledges within a day and asks the customer to respond; pages typically come down within 2–7 days unless the operator files a counter-notice.
- Cloudflare replies with the origin host it forwarded to. If that host is not AWS, send the same notice there too.
- If the operator files a counter-notice, the material can go back up after 10–14 business days unless you file suit; that is the point at which the cease-and-desist and the comparison file matter.
- Keep every reply. The account-holder identity AWS or Cloudflare reveals is what the cease-and-desist is addressed to.
